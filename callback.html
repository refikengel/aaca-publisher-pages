Rückkehr der Anmeldung · Login redirect

Rückkehradresse für die Anmeldung des Betreibers bei einer Plattform, zum Beispiel Instagram, Facebook, Pinterest oder Google.

Redirect page for the operator’s login at a platform, for example Instagram, Facebook, Pinterest or Google.

Code nicht weitergeben. Der Code gehört zur Anmeldung des Betreibers. Er darf nicht gepostet, nicht per Chat oder E-Mail verschickt und nicht in Screenshots gezeigt werden. Er wird nur einmal in das Anmeldeskript auf dem eigenen Rechner eingefügt.

Do not share the code. The code belongs to the operator’s login. It must not be posted, sent by chat or email, or shown in screenshots. It is pasted only once into the login script on the operator’s own computer.

Angaben aus der Adresse · Values from the address

Die Plattform hat einen Code übergeben. Den Code kopieren, einmalig in das Anmeldeskript einfügen und dieses Fenster danach schließen. Autorisierungscodes sind in der Regel nur kurz gültig und nur einmal verwendbar.

The platform returned a code. Copy it, paste it once into the login script, and close this window afterwards. Authorization codes are usually valid only briefly and can be used only once.

Die Plattform hat die Anmeldung mit einer Fehlermeldung beendet. Es wurde kein Code übergeben. Die Anmeldung im Skript neu starten.

The platform ended the login with an error. No code was returned. Restart the login in the script.

Es wurde kein Code übergeben. Die Plattform ruft diese Seite nach der Anmeldung auf; ohne Anmeldung gibt es hier nichts anzuzeigen.

No code was passed. The platform opens this page after the login; without a login there is nothing to show here.

Was diese Seite tut · What this page does

  • Sie liest die Angaben aus der Adresszeile und zeigt sie nur in diesem Browserfenster an.
  • Sie speichert nichts, sendet nichts und lädt nichts nach. Das einzige Skript ist callback.js auf derselben Domain.
  • Sie entfernt die Angaben nach dem Anzeigen aus der Adresszeile. Ein Neuladen zeigt sie nicht erneut an; dann die Anmeldung neu starten.
  • It reads the values from the address bar and shows them only in this browser window.
  • It stores nothing, sends nothing and loads nothing. The only script is callback.js on the same domain.
  • After showing the values it removes them from the address bar. Reloading does not show them again; restart the login in that case.
